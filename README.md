# Pomodoro Timer

간단한 뽀모도로 타이머 웹앱

## Stack

- React
- TypeScript
- Vite

## Goal

복잡한 기능 없이 집중 시간을 설정하고 바로 시작할 수 있는 심플한 타이머 만들기

핵심:

- 빠르게 실행
- 직관적인 UI
- 최소한의 기능

### Timer

- [ ] 시간 설정
- [ ] 시작
- [ ] 일시정지
- [ ] 초기화

### Alarm

- [ ] 종료 시 알림음 재생
- [ ] 브라우저 알림 (선택)

### Presets

- [ ] 직접 입력

- 설정 시간

## Technical Notes

### Timer accuracy

`setInterval`만 쓰지 않고 기준 시간을 저장해서 남은 시간을 계산

예시:

- 시작 시각 저장
- 종료 시각 계산
- 현재 시각 기준 남은 시간 계산

## Storage

- 마지막 설정 시간
- 알림 설정 여부
